# Rà soát và sửa lỗi — 26/10/2026

## Phạm vi

Đọc lại các luồng xác thực, phân quyền, công việc, dự án, thông báo và AI; đối chiếu các báo cáo sửa lỗi trước. Chạy bộ test hiện có, bổ sung ca hồi quy và sửa các lỗi xác nhận được. Không dùng database phát triển: test API chạy PostgreSQL nhúng và upload trong thư mục tạm. AI dùng bộ xử lý nội bộ, không gọi provider trả phí.

Tổng bộ test cuối: **143 ca**, thêm **13 ca** so với baseline. [Log frontend cuối](test-evidence/2026-10-26-frontend-final.txt).

## Giới hạn và chạy lại

Đợt này không kiểm thử trực quan trên trình duyệt, tải lớn, SMTP/OAuth thật hoặc provider AI bên ngoài. Các kết quả trên xác nhận những luồng đã kiểm tra, không chứng minh toàn bộ ứng dụng không còn lỗi. Không có migration hay thao tác sửa dữ liệu người dùng.

```powershell
npm --prefix FrontEnd ci
npm test
npm run build
git diff --check
```

Đã build frontend tại chỗ; cần khởi động lại backend đang chạy để nạp thay đổi. Các sửa đổi chưa commit hoặc push.
